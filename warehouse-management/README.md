# 倉庫管理システム

## 概要
intra-mart環境で動作する実用性の高い倉庫管理システムです。在庫管理、入出庫管理、棚卸し、レポート機能など、実際の業務で必要な機能を網羅しています。

## 🚀 主要機能

### 📦 在庫管理
- **商品管理**: 商品情報の登録・編集・削除
- **在庫追跡**: リアルタイム在庫数の管理
- **ロケーション管理**: 倉庫内の保管場所管理
- **在庫アラート**: 低在庫・在庫切れの自動通知

### 🔄 入出庫管理
- **入庫処理**: 商品の入庫登録と在庫更新
- **出庫処理**: 商品の出庫登録と在庫更新
- **移動処理**: 倉庫内での商品移動
- **取引履歴**: すべての入出庫履歴の記録

### 📊 棚卸し・品質管理
- **サイクルカウント**: 定期的な在庫確認
- **品質チェック**: 商品の状態管理
- **有効期限管理**: 期限切れ商品の自動検出
- **ロット管理**: ロット番号による追跡

### 📈 レポート・分析
- **在庫レポート**: 現在の在庫状況
- **取引レポート**: 入出庫の統計情報
- **価値分析**: 在庫の総価値計算
- **トレンド分析**: 在庫変動の傾向

### ⚙️ システム管理
- **ユーザー管理**: 権限別のアクセス制御
- **倉庫設定**: 複数倉庫の管理
- **カテゴリ管理**: 商品分類の設定
- **バックアップ**: データの定期バックアップ

## 🚀 セットアップ手順

### 1. 前提条件
- Java 11以上
- Maven 3.6以上
- PostgreSQL 12以上
- Tomcat 9以上

### 2. データベースセットアップ
```sql
-- データベース作成
CREATE DATABASE warehouse_db;

-- ユーザー作成
CREATE USER warehouse_user WITH PASSWORD 'warehouse_password';

-- 権限付与
GRANT ALL PRIVILEGES ON DATABASE warehouse_db TO warehouse_user;

-- データベースに接続
\c warehouse_db

-- スキーマ作成
CREATE SCHEMA warehouse_schema;

-- 権限付与
GRANT ALL PRIVILEGES ON SCHEMA warehouse_schema TO warehouse_user;
```

### 3. アプリケーション設定
1. `src/main/resources/database.properties` の接続情報を確認
2. 必要に応じてデータベース接続情報を変更

### 4. ビルドと実行
```bash
# 依存関係のダウンロード
mvn clean install

# Tomcatでアプリケーション起動
mvn tomcat7:run
```

### 5. アクセス
- アプリケーション: http://localhost:8080/warehouse/
- ダッシュボード: http://localhost:8080/warehouse/dashboard

## 📊 データベース設計

### 主要テーブル

#### products (商品)
- 商品ID、商品コード、商品名
- カテゴリ、ブランド、価格
- 最小・最大在庫レベル

#### inventory (在庫)
- 在庫ID、商品ID、倉庫ID
- 数量、利用可能数量、予約数量
- ロケーション、ロット番号

#### transactions (取引履歴)
- 取引ID、取引タイプ（入庫/出庫/移動）
- 商品ID、数量、取引日時
- 処理者、ステータス

#### warehouses (倉庫)
- 倉庫ID、倉庫名、住所
- 管理者、連絡先
